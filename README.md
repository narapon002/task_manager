# โปรโตไทป์ติดตามโปรเจค (ทดลอง)

โปรโตไทป์เว็บแอปแบบไฟล์เดียว ใช้ทดลองขั้นตอนการทำงาน สิทธิ์ของแต่ละบทบาท และหน้าจอ ยังไม่ใช่ระบบจริง

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวโปรโตไทป์ทั้งหมด (HTML, CSS, JavaScript) |
| `Code.gs` | สคริปต์ Google Apps Script สำหรับเสิร์ฟ `index.html` เป็นเว็บแอป |
| `appsscript.json` | ค่าการตั้งค่าโปรเจค Apps Script (เขตเวลา สิทธิ์การเข้าถึง) |
| `README.md` | คู่มือนี้ |

## วิธีที่ 1: ใช้ GitHub Pages (แนะนำ ง่ายที่สุด)

ใช้ได้เมื่อมีบัญชี GitHub และต้องการลิงก์สาธารณะแบบเว็บไซต์ธรรมดา

1. สร้าง repository ใหม่ เช่น `project-tracker-prototype` (ตั้งเป็น Public หรือ Private ตามต้องการ; GitHub Pages แบบ Private ต้องใช้แพ็กเกจที่รองรับ)
2. อัปโหลด `index.html` และ `README.md` ขึ้น branch `main` ที่ root ของ repository
3. ไปที่ **Settings > Pages** แล้วตั้ง Source เป็น `Deploy from a branch`, Branch เป็น `main` และโฟลเดอร์เป็น `/ (root)`
4. รอประมาณ 1 นาที ลิงก์จะเป็นรูปแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`
5. ส่งลิงก์ให้ทุกคนทดลองใช้ได้เลย

## วิธีที่ 2: ใช้ Google Apps Script

ใช้เมื่อต้องการลิงก์ผ่าน Google Workspace หรือจัดการสิทธิ์การเข้าถึงผ่านบัญชี Google

1. ไปที่ https://script.google.com แล้วกด **New project** ตั้งชื่อโปรเจค
2. ลบโค้ดเริ่มต้นใน `Code.gs` แล้ววางเนื้อหาจากไฟล์ `Code.gs` ในชุดนี้
3. กด **+ > HTML** ตั้งชื่อไฟล์เป็น `index` (ระบบจะเพิ่ม `.html` ให้เอง) แล้ววางเนื้อหาทั้งหมดจาก `index.html`
4. ไปที่ **Project Settings** (ไอคอนเฟือง) แล้วเปิด **Show "appsscript.json" manifest file in editor** จากนั้นแทนที่เนื้อหาของ `appsscript.json` ด้วยไฟล์ในชุดนี้
5. กด **Deploy > New deployment** เลือกประเภท **Web app**
6. ตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone** (หรือ **Anyone within [โดเมนองค์กร]** ถ้าใช้ Google Workspace เพื่อจำกัดให้เฉพาะคนในองค์กร)
7. กด Deploy อนุญาตสิทธิ์เมื่อระบบขอ แล้วคัดลอก **Web app URL** ไปแจกจ่ายให้ทุกคน

หมายเหตุ: ทุกครั้งที่แก้โค้ด ต้องกด **Deploy > Manage deployments > Edit > New version** เพื่อให้ลิงก์ใช้เวอร์ชันล่าสุด

## ข้อจำกัดที่ควรทราบก่อนแจกจ่าย

- **ข้อมูลไม่ถูกบันทึก:** ทุกอย่างที่เพิ่มหรือแก้ไขอยู่ในหน่วยความจำของเบราว์เซอร์ รีโหลดหน้าแล้วข้อมูลจะกลับไปเป็นค่าตัวอย่างเริ่มต้น และแต่ละคนจะเห็นข้อมูลของตัวเองแยกกัน
- **ไม่มีรหัสผ่าน:** หน้าเข้าสู่ระบบเป็นการเลือกบัญชีตัวอย่าง ใครก็เข้าเป็นบทบาทไหนก็ได้ ห้ามใช้กับข้อมูลจริงหรือข้อมูลลับ
- **ไม่มีการแจ้งเตือนทางอีเมล และไม่มีการแนบไฟล์**
- **ข้อมูลตัวอย่างและชื่อในระบบเป็นของสมมติ** ไม่ควรแชร์ลิงก์นอกกลุ่มทดลอง
- ใช้งานได้บนเบราว์เซอร์สมัยใหม่ แต่หน้าจอออกแบบสำหรับจอคอมพิวเตอร์เป็นหลัก

## ขั้นต่อไปที่วางแผนไว้

- เชื่อม Google Sheets เป็นฐานข้อมูลผ่าน Apps Script (`Code.gs` จะเพิ่มฟังก์ชันอ่านและเขียนข้อมูล)
- ระบบรหัสผ่านและการเข้าสู่ระบบจริง
- แนบไฟล์ขนาดไม่เกิน 10 MB ผ่าน Google Drive
- ส่งอีเมลแจ้งเตือนผ่าน MailApp
- ไทม์ไลน์แบบ Gantt พร้อมเส้นทางวิกฤต และการปรับตารางอัตโนมัติ
